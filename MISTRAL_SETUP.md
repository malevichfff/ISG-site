# Подключение Mistral AI для артефактов ISG

## 1. Создать Cloudflare Worker
1. Открой Cloudflare Dashboard -> Workers & Pages -> Create -> Worker.
2. Назови Worker, например `isg-mistral-artifacts`.
3. Замени код Worker содержимым файла `mistral-worker.js` из этого репозитория и нажми Deploy.

## 2. Добавить секрет Mistral
1. В настройках Worker открой Settings -> Variables and Secrets.
2. Добавь Secret с именем `MISTRAL_API_KEY` и вставь свой ключ из Mistral Console.
3. Сохрани и повторно разверни Worker, если Cloudflare попросит.

Ключ хранится только в Cloudflare Worker, его нельзя добавлять в index.html или Firebase.

## 3. Подключить Worker на сайте
1. Открой вкладку АРТЕФАКТЫ и форму добавления.
2. Выбери фотографию и нажми «Добавить артефакт».
3. При первом запуске сайт попросит URL Worker. Вставь адрес вида `https://isg-mistral-artifacts.<твой-subdomain>.workers.dev`.
4. Адрес запомнится в браузере.

## Поведение распознавания
- Mistral Vision использует модель `mistral-small-latest`.
- Название и редкость считываются с изображения. Если название или редкость не видны, сохранение отменяется и предлагается другое фото.
- Свойства добавляются только если их подпись и числовое значение видны на изображении. Отсутствующие свойства не записываются.
- Тип артефакта и цена выбираются/вводятся игроком.
- Перед записью в Firebase показывается сводка распознавания и запрос подтверждения.

## Важно
Worker сейчас разрешает CORS-запросы с любых сайтов, чтобы его можно было подключить к GitHub Pages и другим доменам. Для публичного проекта рекомендуется ограничить Origin доменом сайта и добавить rate limiting / проверку авторизации, чтобы посторонние не расходовали баланс Mistral.
