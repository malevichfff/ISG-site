# Подключение Mistral AI для артефактов

1. Создай Cloudflare Worker и вставь код из `worker.js`.
2. В настройках Worker → Variables and Secrets добавь секрет `MISTRAL_API_KEY` со своим ключом Mistral.
3. Опубликуй Worker и скопируй его HTTPS URL.
4. Открой вкладку «АРТЕФАКТЫ» на сайте. При первом распознавании сайт попросит URL Worker — вставь его.

ИИ считывает название и редкость (Мусорный, Обычный, Необычный, Редкий, Легендарный), а также только видимые числовые свойства. Отсутствующие свойства не записываются. Тип артефакта и цену вводит игрок. Перед сохранением показывается сводка для подтверждения.

Ключ Mistral хранится только в секретах Cloudflare Worker — не добавляй его в HTML или Firebase.
Для продакшена замени разрешённый Origin в worker.js на точный домен сайта.
